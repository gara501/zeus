# Art and Interface

- Zeus, Amalthea, eagle, monster, element, tileset and story sprites: supplied by the game author.
- **Tiny RPG – Mana Soul GUI**, Gabriel “tiopalada” Lima. Frames, portrait and buttons. [Original page](https://tiopalada.itch.io/tiny-rpg-mana-soul-gui). CC0 1.0; original notice in `src/sprites/ui/LICENSE.html`. Colors adapted with CSS filters; original sheets preserved.
- **Cinzel**, Natanael Gama. [Google Fonts](https://fonts.google.com/specimen/Cinzel). SIL Open Font License 1.1, included in `src/fonts/Cinzel-OFL.txt`.
- **Pixelify Sans**, Stefie Justprince. [Google Fonts](https://fonts.google.com/specimen/Pixelify+Sans). SIL Open Font License 1.1, included in `src/fonts/PixelifySans-OFL.txt`.
- Vector cave background and interface adaptation: created for this project with assistance from OpenAI Codex.

Fonts and assets are bundled with the game; no external services are needed to play.
